# 為什麼只能開到 90 度，以及為什麼整個箱子拉不動

兩個限制都是**我們自己寫死的**，不是物理。

## 一、卡在 90 度多：關節上限被寫死在 100°

`author_carton` 把每個摺痕的角度限制在 −5°～100°，所以蓋子過了垂直一點就撞到上限，
整個紙箱永遠攤不開。

真實 RSC 的蓋子可以一路翻到箱壁外側貼平，而我們的摺痕本來就長在**牆的外表面**上，
所以 180° 剛好貼平、不會穿模。現在限制是可設定的，資產用 **−5°～179°**（留最後一度避開退化的完全平貼姿態）。

實測（[20260917T143848Z](../../runs/20260917T143848Z_ext1_carton_pull)）：主蓋翻到 **179.0°**，放手後**停在 179.0°**，
塑性參考角 176.5°。28 項 checks 全過。

## 二、整個箱體拉不動：底部被 FixedJoint 釘在世界座標

那是早期蓋子實驗要的（固定底），對機器人工作流不對。現在 `base_mode` 可選：

- `fixed`：釘死（蓋子實驗用）
- `free`：拿掉那個 joint，箱子站在地面上，可以被推、被拖

箱體質量也不再是隨手填的 0.2 kg，改成由板材面密度算底＋四面牆：**0.0846 kg**。

實測自由箱體（[20260917T143819Z](../../runs/20260917T143819Z_ext1_carton_pull)）：

| 量的事 | 結果 |
| --- | --- |
| 側向力掃描到箱子滑動 | **0.7 N** |
| 隱含摩擦係數 | 0.84（**模擬器預設材質**，不是我們宣告或量測的） |
| 用 0.25 N 拉一片蓋子時箱體位移 | 2.3e-8 m（等於不動） |

中途兩個亂猜的推力已作廢並保留記錄：0.5 N 完全推不動，20 N 把箱子丟出 33 公尺——
所以滑動門檻改成跟蓋子開啟力一樣用掃描量的。

## 一個被這次改動抓到的測試錯誤

編輯器入口測試原本用 2 N 拉一片蓋子。對自由箱體而言那是它自重（0.83 N）的 2.4 倍，
整個紙箱被丟飛，四片蓋全部甩開（165°／149°／87°／93°）。
已改用實測的 0.30 N，並新增一項檢查：拉一片蓋子時箱體不得移動（實測 1.3e-8 m）。

## 還沒做的

板材與地面的**物理材質尚未宣告**，所以 0.84 這個摩擦係數是模擬器預設值，不是紙箱對桌面的量測值——
這是下一件該做的事。摺痕的 4° 回彈與 0.085 N 邊緣力同樣仍是推導目標，不是真實紙箱量測。
