# 你是對的：完全打開是 270°，不是 180°

上一輪我把上限提到 179° 並說那是「貼平在牆外側」，**那是錯的**。

繞摺痕軸旋轉時，蓋子的長度方向對應到世界座標是 (cos, sin)：

| 關節角度 | 蓋子指向 | 實際樣子 |
| --- | --- | --- |
| 0° | +y | 蓋住開口（關閉） |
| 90° | +z | 直立 |
| 180° | −y | **水平往外伸，像一塊棚板** |
| **270°** | **−z** | **沿著外牆垂下——這才是完全攤開** |

所以「完全打開」從關閉算起就是 270°，跟你說的一樣。

## 連帶要修的幾何

270° 時板厚方向會指向 +y（朝內），所以若板子以摺痕軸為中心，就會有半個板厚插進牆裡。
現在板子往軸的外側偏移 t/2，並把鉸鏈高度各抬高一個板厚以維持關閉時「主蓋疊在次蓋上」的堆疊
（次蓋 H+t、主蓋 H+2t）。

## 順帶抓到的兩件事

1. `opposite_minor_undisturbed` 原本用 `abs(角度) < 5°` 比較，但沒被碰的蓋子就停在它的 −5° 下限上，
   剛好等於 5 而被判 fail。改成「有沒有被打開」。
2. 我之前說 joint drag「是用約束拖曳」——**那是我沒有根據的推論**。安裝包只告訴我設定名稱是
   `SETTING_MOUSE_GRAB_WITH_FORCE`，且該力由 `pickingForce` 縮放；另一個模式實際用什麼，在封閉的二進位裡。
   程式裡的說明已改成這樣寫。

## 那四個欄位與兩個按鈕

| 元件 | 作用 |
| --- | --- |
| `MajorYN / MajorYP / MinorXP / MinorXN edge force N` | 在**那一片蓋子的外緣**持續施加外力，單位牛頓。正值拉開、負值壓關、0 放手 |
| `Hit 10N / 0.05s` | 敲一下：10 N 維持 0.05 秒的短脈衝 |
| `Release test forces` | 四片全部歸零 |
| `Mouse: force drag` | 內建抓取，施力大小由 `/physics/pickingForce` 縮放（你調到 200 的那個） |
| `Mouse: joint drag` | 同一個抓取但關掉上述施力旗標；它改用什麼機制在封閉二進位裡，哪個比較好用要你試 |

參考力道：外緣 0.14 N 開始開、0.30 N 到 60°、抓在板子中間要兩倍。
