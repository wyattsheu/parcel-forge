# 摺痕上限與自由箱體

使用者回報：滑鼠強度調到約200後推得動；但蓋子只能開到約90°就卡死；另外整個箱體拉不動。

查證：兩者都是 author_carton 裡寫死的設定。關節上限 -5..100 度；底部有 FixedJoint 釘在世界。

改動：crease_lower/upper_limit_deg 可設定，資產採 -5..179（摺痕在牆外表面，180 度貼平）；
base_mode=fixed|free 與 ground_plane；base 質量改由板材面密度計算；
新增量測階段 G（翻到底）與 H（箱體滑動門檻掃描）；scripts/pf-carton-pull 新增 --base。
自由底時只跑箱體相關 checks，因為蓋子那組量測假設箱子不動。

命令與結果：
- `./scripts/pf-carton-pull` → exit 0，runs/20260917T143848Z_ext1_carton_pull，28 checks 全 true，
  翻到底 179.0 度、放手停 179.0 度、塑性參考 176.5 度
- `./scripts/pf-carton-pull --base free` → exit 0，runs/20260917T143819Z_ext1_carton_pull，
  滑動門檻 0.7 N、隱含 μ 0.84（模擬器預設材質）、拉蓋時箱體位移 2.3e-8 m
- `./scripts/pf-carton-editor-test` → exit 0（改用實測 0.30 N，新增 box_not_shoved_by_one_flap）
- `python3 -m unittest discover -s tests` → 160 tests、7 skipped、exit 0
- `./scripts/pf smoke` → exit 0，runs/20260917T143935Z_s1_smoke

過程中作廢並保留的無效量測：0.5 N 推不動、20 N 飛 33 m（改為掃描）；
editor test 原本的 2 N 把自由箱體丟飛（改為 0.30 N）。
