## Why this session exists
The user ran their own known-good WebRTC viewer against an S2 run and saw nothing
but a floor. This is exactly the gap the project's own STATE.md had been honestly
flagging as "not_tested" -- the first time a human actually tried it, it failed.

## Root cause
`IsaacSimRuntime.export_stage()` called `Stage.Export()` without ever setting
`defaultPrim`. The user's viewer loads any file via a USD *reference*
(`GetReferences().AddReference(path)`), and reference resolution goes through the
target layer's defaultPrim. Without one, the reference resolves to nothing. The
viewer's own diagnostic proved it: "1 prims, 0 meshes, bbox 0.0000 x 0.0000 x
0.0000, top-level prims = []". A second, smaller bug: the visible ground slab was
sized off the 20 m physics collider, so even a direct open (not by reference) would
have shown a wall of grey next to the 0.3 m box.
