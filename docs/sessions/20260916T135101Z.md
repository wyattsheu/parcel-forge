## Why
After the defaultPrim fix the box rendered, but the user reported the probe hanging
motionless above it. Three distinct defects were in play; the first fix had only
uncovered the next one.

## Root causes, each established by measurement
1. **PhysicsScene lost through the reference.** Isaac authors it at
   `/PhysicsScene`, a sibling of `/World`; a reference pulls in only the default
   prim's subtree. A script loading the file exactly as the viewer does reported
   `PHYSICS_SCENES_FROM_REFERENCE: []` and the probe unchanged at z=0.47000 after
   3 s. The viewer's own fallback scene does not rescue already-referenced bodies.
2. **PhysX does not write back to USD.** With the scene restored, the tensor API
   read z=0.22500 while USD still read 0.47000. The user's viewer renders from USD
   (`useFabricSceneDelegate=0`), so it showed a frozen cube. This was the defect
   the user actually saw.
3. **Tunnelling at coarse dt** (found incidentally, now D017). At dt=1/60 the probe
   passes through the 5 mm bottom plate to z=0.02000; at 1/240 it lands at 0.22500.
