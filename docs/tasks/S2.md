# Task S2: Fixed open box with a centre drop probe
Status: done (verified)
Depends on: S1 verified (finite-step physics, pose/velocity read-back, offline PNG) — see docs/STATE.md

## Goal
A procedurally built five-plate open box, fixed (not a rigid body), standing on
the world floor. A 4 cm cube dropped from above lands **inside** the box, and the
two deliberately broken variants fail for the right reason.

## Authoritative geometry (handbook section 7, do not re-derive)
Outer L=0.30, W=0.20, H=0.15 m; wall thickness t=0.005 m. Asset local origin is
the centre of the **outer bottom face**, Z up. Sizes below are full extents, not
half-extents. The five plates share no volume.

| plate | size (x,y,z) | centre (x,y,z) |
| --- | --- | --- |
| bottom | (L, W, t) | (0, 0, t/2) |
| wall_x_pos | (t, W, H-t) | ((L-t)/2, 0, (H+t)/2) |
| wall_x_neg | (t, W, H-t) | (-(L-t)/2, 0, (H+t)/2) |
| wall_y_pos | (L-2t, t, H-t) | (0, (W-t)/2, (H+t)/2) |
| wall_y_neg | (L-2t, t, H-t) | (0, -(W-t)/2, (H+t)/2) |

Interior: Li = 0.29, Wi = 0.19, interior height Hi = 0.145 m; interior floor at
local z = t. Reject any input violating L>2t, W>2t, H>t.

Scene per the from-zero brief section 5: the box's outer bottom sits 0.20 m above
the world floor; the 4 cm probe cube falls in from above.

## Scope
- New: `src/parcel_forge/geometry.py` (plate table from L/W/H/t, pure maths, no Kit),
  a box builder using the S1 runtime adapter, and three cases under `cases/`.
- Plates get `CollisionAPI` only. The box root gets **no** `RigidBodyAPI` at S2
  (dynamic box is S4). Colliders are five separate boxes, never one convex hull.
- Reuse the S1 adapter, evidence and profile machinery. Do not touch the S1 profile.

## Cases
| case | construction | expected outcome |
| --- | --- | --- |
| `open_box_normal` | all five plates | probe rests on the **box interior floor** |
| `open_box_sealed` | adds a lid plate over the opening | probe stops **at the box mouth**, never enters |
| `open_box_no_bottom` | bottom plate omitted | probe falls through to the **world floor** |

## Acceptance
- Judge the probe's final height in the **box local frame**, not the world frame.
  World support by the ground floor must never be mistaken for a valid box floor.
  Expected normal resting height: local z = t + probe_size/2 = 0.005 + 0.02 = 0.025 m.
- `open_box_normal` passes; `open_box_sealed` and `open_box_no_bottom` each fail
  with a distinct, named reason. A run where a fault case "passes" is an S2 failure.
- No NaN; finite step budget; clean shutdown; PNG per case with non-blank statistics.
- A geometry unit test in `tests/` checks the plate table against the values above
  and that interior dimensions come out as 0.29 / 0.19 / 0.145 m.

## Evidence
One run directory per case containing manifest.json, environment.json, profile.json,
trajectory.csv, validation-style result JSON, renders/ and summary.md, plus one
combined table naming all three verdicts.

## Failure routing
Probe not entering a normal box -> check plate centres and the collision-vs-visual
split before touching tolerances. Probe sinking through -> check contact offset and
collider presence, never disable collision. Never widen a tolerance to pass a case.

## User learning
Concept: a collider is not the picture. The plates are what physics touches; the
render only shows what a camera would see.
Experiment: change `wall_thickness_m` from 0.005 to 0.02 in the normal case and
predict the new interior floor height before running (answer: 0.02 + 0.02 = 0.04 m).
